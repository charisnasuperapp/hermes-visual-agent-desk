# Charisna Office Workspace · Agent Join Guide

## Information
- Office URL: http://localhost:19000 (or your LAN/toggled URL)
- Join Key: [Input your join key, e.g. ocj_xxx]
- Agent Name: [Your Agent Name]

## Steps to Connect
1. Ensure authorization from the system architect.
2. Send join request to:
   POST http://localhost:19000/join-agent
   Payload:
   {
     "name": "[Agent Name]",
     "joinKey": "[Join Key]",
     "state": "idle",
     "detail": "Ready in workspace"
   }
3. The agent will appear in the Charisna Office Workspace visual desk.
